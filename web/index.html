USAGE LIMIT

      
      
On: when the 5-hour or weekly limit is reached, queued tasks wait and any task cut off goes back in the queue. All of them resume by themselves when the limit resets.
Off: tasks keep launching and fail until the limit resets.

      

    

    

      
CODE CHANGES

      
      
On: each edit pops up in a small window beside the agent that made it (or beside the orb for the main session), linked to it by a line.
Off: changes are only listed in Comms and in each task's details; click one to open it.
Drag a window's title to move it, and its edges or corner to resize it. New windows open at the last size you set.

      

    

    

      
NOTIFICATIONS
